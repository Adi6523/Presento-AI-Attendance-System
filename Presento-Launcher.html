System Quickstart

1
Double-click Start-Presento.bat in the project folder — it opens both server windows automatically.
2
Wait ~7 seconds for the servers to initialise (the dots above turn green).
3
Click Open Presento Dashboard or browse to http://localhost:5173.
4
Keep both Presento API and Presento Dashboard command windows open while using the system.
